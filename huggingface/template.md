# SAM3 Pseudo-Labels & YOLOv8 Models for Pig Monitoring (Based on PigLife)

> [!WARNING]
> ### ⚠️ No Images Included (Copyright Restrictions)
> Due to the copyright and licensing restrictions of the original **PigLife dataset by UIUC**, this repository **DOES NOT contain any original images**. 
> This dataset provides **only the pseudo-labels (annotations)** generated by the Segment Anything Model 3 (SAM3) in YOLO format, alongside the **YOLOv8 models** trained on these labels.
> 
> To use these annotations, you must legally acquire the original images directly from the [UIUC PigLife official source](LINK_TO_PIGLIFE) and pair them using our provided structure.

## Dataset & Project Summary

This project provides high-quality pseudo-labels for pig detection and segmentation, generated using **SAM3** on the widely used PigLife dataset. Since manual annotation of dense livestock environments is prohibitively expensive, we leverage SAM3 to generate robust pseudo-masks and bounding boxes.

Additionally, we provide **YOLOv8 weights** (Nano, Small, Medium) trained entirely on these SAM3-generated annotations, offering an off-the-shelf solution for precision livestock farming and pig monitoring applications without needing to run the heavy SAM3 inference pipeline.

---

## 🛠️ How to Reconstruct the Dataset

Since we cannot distribute the images, follow these steps to use our labels:

1. **Download Original Images:** Request and download the PigLife dataset from the official UIUC portal.
2. **Download Our Labels:** Clone this Hugging Face repository to get the YOLO-format `.txt` annotation files.
3. **Merge Data:** Place the downloaded images in an `images/` folder and our labels in a `labels/` folder. Ensure the filenames exactly match (e.g., `frame_001.jpg` needs to match `frame_001.txt`).

---

## 🤖 Trained YOLOv8 Models

We release YOLOv8 models trained on the SAM3 pseudo-labels. These models are lightweight and optimized for real-time inference on edge devices.

### Model Weights Availability
* `yolov8n-pig.pt` (Nano) - *Best for edge devices (Raspberry Pi, Jetson Nano)*
* `yolov8s-pig.pt` (Small) - *Good balance of speed and accuracy*
* `yolov8m-pig.pt` (Medium) - *Highest accuracy for server-side processing*

### Quick Start (Inference)
You can use our trained models directly via the `ultralytics` package by passing the Hugging Face URL:

```python
from ultralytics import YOLO

# Load the trained model directly from Hugging Face
model = YOLO("hf://YOUR_USERNAME/YOUR_MODEL_NAME/yolov8s-pig.pt")

# Run inference on an image or video
results = model.predict("path/to/your/pig_image.jpg", save=True)
results[0].show()
```

## Limitations
* **Pseudo-Label Noise:** The labels were generated by a foundation model (SAM3), not human experts. Some false positives or missed occluded pigs may exist.
* **Domain Shift:** The models are optimized for the camera angles and lighting conditions present in the PigLife UIUC dataset. Performance may vary in vastly different farm setups.
